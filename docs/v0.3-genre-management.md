# Genre management in 0.3

Genres are private, curated labels. A book may belong to several genres. The original single-value source genre and subjects remain visible as imported metadata; accepting a genre does not rewrite the book, its OPF, or Nextcloud tags.

## Use it

1. Open **Genres** in Library to create a genre or browse the current list. Selecting a genre opens its books in the catalogue.
2. On a book's **Full details** page, type at least three letters to find a genre, select it, or create and add a new one. Remove a chip to remove that book's assignment.
3. In **Genres → Suggestions to review**, inspect names found in source genre metadata, recognized subject terms, and clearly named folders. Accept the suggested name, enter an existing or new genre name to map it, or ignore the suggestion. An accepted mapping applies to other books carrying the same candidate. Ignored suggestions stay ignored on rescans.
4. Discovery of existing books runs in bounded background slices; **Discover genres in existing books** advances it while the page is open. **Apply approved suggestions** advances already accepted mappings.

The suggestion rules are conservative. They do not split a generic comma-separated subject, guess genres from a book title, or automatically publish new genres. An account may deliberately use a broader or narrower vocabulary. The manual picker is available when a book has no useful source hint.

## Storage and scan behavior

`library_genres` stores account-owned identities; `library_item_genres` stores active and deliberately removed book assignments. `library_genre_candidates` stores bounded evidence per book. `library_genre_mappings` stores account-wide accept/map/ignore decisions. `library_items.genre_suggestion_hash` makes the existing-library discovery resumable. New or changed scans update evidence from the metadata retained for the book, including protected manual fields. A changed manual source genre or subject refreshes its evidence immediately. Removing a curated genre assignment remains a deliberate decision and a later rescan does not silently restore it.

The first schema update is additive. Existing source metadata, subject facets, files and manual corrections are preserved. Account and book deletion remove the corresponding genre rows. The genre directory and catalogue filter use indexed relationships; catalogue page projection loads assigned genre chips in one bounded query per page chunk.

## Limits for this slice

The directory and suggestion queue show up to 50 entries at once; search the directory by name, and process suggestions to reveal the next entries. Accepted mappings can be advanced in bounded slices. There is no bulk rename/merge of curated genres, no export to OPF or system tags, and no automatic retraction of an already accepted assignment when its source hint later disappears. Review the assignments on affected books if their metadata changes substantially.
